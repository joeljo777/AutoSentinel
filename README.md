## Real-Time Automotive Event Detection and Safety System

AutoSentinel is an embedded systems project focused on developing a real-time automotive safety monitoring prototype using STM32 microcontrollers, FreeRTOS, and the MPU6050 inertial measurement unit.

### Objectives

* Develop a real-time sensor acquisition system.
* Implement FreeRTOS-based task scheduling and inter-task communication.
* Process inertial sensor data for simulated crash-event detection.
* Explore dual-microcontroller architecture for monitoring and diagnostics.

### Hardware

* STM32F103C8T6 (Blue Pill) × 2
* MPU6050
* 0.96-inch I²C OLED Display
* ST-Link V2
* Additional electronic components

### Software

* Embedded C
* STM32CubeIDE
* FreeRTOS
* STM32 HAL
* Git and GitHub

> This project is an educational prototype. It is not intended for deployment in a real vehicle or connection to a pyrotechnic airbag system.
